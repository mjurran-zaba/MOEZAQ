# MOEZAQ

Personal landing page for Muhammad Zaqi Prasetyo.

Live site: https://mjurran-zaba.github.io/MOEZAQ/

MOEZAQ is my home on the web. A single page where I put my projects, my journey, and the things I'm currently working on.

No blog. No noise. Just the work.

## What's inside

### NOTEZ
My main project. An offline-first Markdown notes app for Android.

- Small APK, around 3.0MB
- Works fully offline, no cloud, no account
- Local database with Room SQLite
- Open source under GNU GPL-3.0

### ZCODE
A modular developer toolchain I'm building. Still in development, not released yet.

### Theme Gallery
A collection of 21 color themes taken directly from NOTEZ. You can preview them live on the site.

## How it's built

I built this page with plain HTML, CSS, and JavaScript. No frameworks, no CSS libraries, no build step.

I did it on purpose. I wanted the page to load fast, stay light, and be easy to maintain.

- Vanilla HTML5, CSS3, and ES6+ JavaScript
- Custom CSS variables for theming
- Self-hosted background video, around 1.6MB
- Mobile-first layout
